# iOS 页面与交互走查

日期：2026-09-05。承接 [HIG 设计审视](ios-hig-audit.md)，对当前 iOS 工程的所有页面及主要弹窗进行实际操作，并直接修复发现的问题。

环境：Xcode 26 / iOS 26；iPhone 16 Pro 普通字号、浅色模式；iPhone SE 第三代最大辅助功能字号、深色及高对比度。使用独立演示数据。AI 连接本机固定响应服务；设备工具仅执行 `--help`，没有读写真实日历、提醒事项或剪贴板内容。

## 已修复的问题

| 范围 | 复现的问题 | 修改与验证 |
| --- | --- | --- |
| 记录筛选 | 快速切换“排除工作 → 全部 → 无标签”闪退；旧索引 9 被用于只有 2 项的新列表 | 移除失效的程序滚动，筛选后重建列表；随机回顾直接使用随机排列。重复切换包含、排除、全部、无标签、随机均通过；异步搜索使用最新筛选快照 |
| 工作流执行 | 空工作流或未填写 AI 指令的步骤可能消耗草稿却没有有效处理 | 执行前校验启用步骤与指令，保留草稿并提示缺少的配置；执行层也校验。实测空工作流弹出提示，文字和标签保留 |
| AI 输入 | 未配置密钥时发送会清空输入内容 | 提前校验配置。实测失败时问题仍保留在输入框 |
| 权限队列 | 并发权限请求相互覆盖，任务可能一直等待 | 请求按队列展示，取消可移除排队项，同会话重复请求复用授权。实测日历允许后显示提醒事项请求，拒绝后会话正常结束 |
| 权限范围 | “本次会话允许”实际使用全局会话标识 | 设备工具接收真实会话 ID；工作流每次执行独立。实测新会话再次出现日历授权；状态回归通过 |
| 草稿编辑器 | SwiftUI 更新期间同步改变 UIKit 焦点并回写文字，产生 AttributeGraph 更新循环 | 延后焦点变更、屏蔽程序同步回调、避免重复写草稿。重新启动、输入、清除/恢复、页面往返后未再出现循环 |
| 草稿标签 | 新建但仅用于草稿的标签，关闭选择页后再打开消失 | 候选项包含当前草稿、初始选择与新建标签。实测重新打开后标签可见且选中 |
| 标签合并 | 重命名到已有标签后出现重复值 | 合并去重并保留顺序，草稿使用草稿保存路径。实测重命名为“灵感”后只保留一个标签，文件内容无重复 |
| HTTP 表单 | 主机字段接受带协议或路径的无效值 | 校验裸主机及 1–65535 端口，展示输入规则。实测 `http://localhost` 不能保存，改回 `localhost` 后保存恢复；端口越界不能保存 |
| 模型选择 | 获取列表擅自改掉自定义模型，并隐藏手动输入 | 始终保留输入框，列表包含当前自定义值，刷新只更新候选项。实测 `custom-model` 保留，长模型名称换行正常 |
| 模型加载 | 更改 API 地址后，旧请求可能回写列表或错误 | 取消旧任务并校验请求标识。实测慢请求中途切换地址后不回写旧列表，加载状态复位 |
| 技能数量 | 已有技能首次进入设置却显示 0 | 设置页加载技能数据。实测有技能显示 1，空数据集显示 0 |
| AI 排版 | 回复直接显示 Markdown 标记，缺少文字层级 | 原生文字块显示标题、列表、引用与代码，保留文字选择和系统字号；标题带辅助功能 heading 语义。实测标题、列表及大字号回复 |
| AI 滚动 | 回复增长被误判为用户离开底部，新内容跑到屏幕外 | 根据用户滚动阶段控制跟随，使用稳定的底部锚点。实测自动跟随；上滑后继续输出几十段仍保持阅读位置；停止后恢复输入 |
| 图标搜索 | 无结果混用英文，透明背景透出下层页面 | 中文空态、关闭自动纠正、不透明系统背景。实测空态及正常搜索选择 |
| 空工作流 | 重复显示两个“添加步骤”，同时显示无意义的编辑按钮 | 只保留一个添加入口，隐藏编辑与排序说明。实测空工作流页面 |
| 授权参数 | 带空格的参数及负数相对日期显示不完整 | 保留原始命令，展示与执行共用分词规则。带引号参数、`-7d` 和 flag 回归通过 |
| 错误反馈 | 网络失败、权限拒绝信息混用英文且缺少操作指引 | 常见网络错误及权限说明改为中文，保留重试入口。实测连接失败提示检查服务器地址与网络 |
