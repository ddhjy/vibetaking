# 随心记隐私政策

更新日期：2026-06-10

随心记是一款纯文本速记应用。我们尽量让数据留在你的设备和你自己的账户中。本政策说明应用如何处理信息。

## 我们不收集的内容

随心记不包含广告 SDK，不进行跨 App 或跨网站追踪，也不会向开发者服务器上传分析数据。

## 本地与 iCloud 数据

你在应用中创建的草稿、记录、标签和 Workflow 配置会保存在设备本地。启用 iCloud Drive 时，记录会写入你自己的 iCloud 容器，以便在设备间同步。iCloud 数据由 Apple 提供同步服务，受你的 Apple ID 与 iCloud 设置管理。

AI API Key 会保存在系统 Keychain 中。模型、接口地址和其他偏好设置可能保存在设备的 UserDefaults 中。

## 可选 AI 功能

如果你在设置中配置了 AI 服务，应用会在你主动触发 AI Workflow 或刷新模型列表时，把相关文本、提示词或请求发送到你配置的 AI 服务地址。该服务可能由第三方提供，其数据处理方式取决于对应服务的隐私政策。

如果你不配置或不使用 AI 功能，应用不会向 AI 服务发送你的记录内容。

## 可选局域网功能

应用包含可配置的 HTTP 发送能力，用于和你指定的局域网服务配合。只有在你配置并触发相关 Workflow 时，应用才会把文本发送到你指定的地址。

## 剪贴板与文件

当你主动使用复制功能时，应用会把选中的文本写入系统剪贴板。导入和导出功能只处理你选择的 Markdown、文件夹或 ZIP 文件。

## 联系方式

如需隐私或支持相关帮助，请通过项目支持页面联系开发者。
