# 随心记 iOS：Apple HIG 审视与修改清单

审视日期：2026-09-05。范围是 `apps/ios/vibetaking` 的全部 SwiftUI 页面、UIKit 编辑器、导航、列表、表单、筛选、弹窗、空态及加载/失败状态。macOS 菜单栏伴侣不属于本次 iOS 界面改造。

## 修改清单

下列项目根据代码审查与模拟器原始界面形成，修改均已落地；实测范围和限制见文末。

| 界面 / 元素 | 发现的问题 | 设计修改 |
| --- | --- | --- |
| 全局颜色 | 固定 RGB 强调色未定义深色及高对比度变体，不同页面操作色不一致 | 保留靛蓝识别，采用系统 indigo；背景、正文和辅助信息使用系统语义色 |
| 全局文字、动画 | 自定义字号和弹簧动画未完整响应辅助功能 | 使用语义字体；UIKit 正文跟随 Dynamic Type；减少动态效果时禁用自定义位移动画 |
| 首页底部操作 | 工作流无限增加，标签长名称挤占搜索和清除位置 | 工作流横向滚动；辅助功能字号下转为系统菜单；次要动作保持至少 44 pt；标签用图标和数量表达 |
| 首页工作流 | 图标缺少可见名称；专注只能长按进入和退出 | 显示工作流名称，菜单提供专注入口，专注时提供明确退出按钮和辅助功能动作 |
| 首页清除 | 清除与恢复共用叉号及名称，状态含义不明确 | 根据状态显示清除、恢复或清除标签；无可执行操作时禁用；辅助功能反馈操作结果 |
| 首页编辑器 | 固定 17 pt；占位与输入的读屏语义不清；延迟键盘任务可能干扰新页面 | 系统正文、动态字号、编辑器名称；模态/导航期间停止抢占焦点 |
| 记录导航和选择 | 页面标题缺少位置含义；零条选择时无法全选；批量图标缺少名称 | 使用“记录”和所选数量标题；选择工具栏始终可用，依赖选择的操作明确禁用；全选状态仅计算可操作的已下载记录 |
| 记录列表 | 自绘阴影卡片及固定 16 pt 元数据行；长标签易截断或溢出 | 系统分组列表；正文与元数据自然伸展；标签、菜单分别提供明确操作 |
| 记录菜单和复制 | 省略号实际打开标签；复制成功状态未呈现；删除即时发生 | 省略号打开操作菜单；标签有独立入口；显示复制反馈；删除前确认 |
| 记录导出 | 失败只写日志，用户没有反馈 | 原生错误提示 |
| 记录空态 / 同步提示 | 空态误称草稿自动进入记录；筛选无结果缺少恢复入口；橙色小字难读 | 原生 ContentUnavailableView，准确说明保存方式；提供清除筛选及写记录操作；中性同步状态提示 |
| 标签筛选 | 32 pt 左右的热区；排除状态依赖颜色；多级筛选可能占满屏幕 | 至少 44 pt；包含、排除都有符号和读屏状态；限制筛选区高度并支持滚动 |
| 标签选择 | 自绘列表；打开后直接关闭可能清除原标签；本地新标签可能不可见 | 原生多选列表；保留既有选择；稳定标识；本地新标签立即显示 |
| 标签创建 / 重命名 | 200 pt 弹窗不能适应大字；名称提示输入后消失；创建后选择状态不同步 | 原生 Form、常驻名称、可扩展弹窗、键盘提交；创建与重命名同步本地选择 |
| 批量标签 | 创建标签仅写入第一条记录；部分选中语义不清 | 新标签应用于本次所选记录；混合状态使用减号和明确的辅助功能描述 |
| 标签推荐标记 | 过小彩色文字；长标签与标记争抢宽度 | 语义字号、中性色、符号区分；大字体下纵向排布 |
| 设置 | 没有明确完成入口；密钥/地址靠占位辨认；模型获取前无法手动编辑 | 原生完成按钮；常驻字段名称；安全字段关闭自动纠错与大写；支持手动模型名称 |
| 设置状态 / 迁移 | 禁用原因不够明确；导入选择文件后直接覆盖配置 | 可理解的加载/错误/禁用说明；替换配置前给出明确确认 |
| 技能 / 设备权限设置 | 术语、长描述截断；权限选项在窄行拥挤 | 中文“技能”标题、原生空态、可换行说明；权限使用导航式选择器 |
| 工作流列表 / 详情 | 英中术语混用；手机使用 sidebar 风格；缺少关闭；自制显隐按钮 | 中文“工作流”；手机 insetGrouped、iPad 保留 split view；关闭入口；系统 Toggle |
| 工作流删除 / 步骤 | 即时删除；整行手势包裹开关，容易混淆编辑与启停 | 删除确认；独立编辑按钮和有名称的 Toggle；保留系统重排 |
| 步骤编辑 | 复制、保存步骤打开空白表单；主机端口无常驻名称与校验 | 只读“步骤详情＋完成”、原生提示词编辑器、地址与端口标签、有效端口校验 |
| 设备绑定 | 长名称挤压解绑操作；连接中没有表单状态 | 支持纵向排布、清晰连接进度与解析失败信息 |
| 图标选择 | 固定六列与固定单元宽度可能重叠；无选中语义、无搜索空态 | 自适应网格、选中勾号和名称、支持中文类别搜索、原生无结果页 |
| AI 会话 | 装饰性玻璃输入框；发送与停止无名称；技术标识占据会话主层 | 输入框使用内容层背景，原生操作按钮；工具标识移入展开详情；停止操作取消实际发送任务 |
| AI 内容 / 空态 | 示例仅是文字；消息角色和工具状态读屏不明确；错误仅橙色 | 示例可填入输入区，采用系统主文字色提高可读性；正文可选择，角色与状态可读；错误用图标加文字 |
| 历史会话 | 删除立即生效；无结果只一行文字 | 系统空态、清晰完成入口、删除确认 |
| 设备授权 | 固定 medium 高度、参数截断、按钮可能出屏；原本 30 秒自动关闭，影响阅读 | 可滚动详情、完整参数、medium/large 适配、明确本次会话授权范围、固定底部决策按钮；取消阅读时限，任务取消仍立即拒绝并结束等待 |
| 统计日历 | 固定 44 pt 七列在窄屏越界；月份按钮偏小；日期缺少读屏名称 | 自适应日历，窄屏/辅助功能字号改用日期列表；完整日期与记录数；44 pt 月份操作；大字体使用月份缩写，避免长单词从中间断行 |
| 调试页 | 空白选项列表 | 原生说明性空态与完成按钮 |

## 经检视保留

- 应用图标沿用现有简洁图形与 Icon Composer 容器，保持产品识别。
- 系统键盘、文件导入器、分享面板和系统权限提示使用原生实现。
- 编辑器仍默认打开并聚焦，已有草稿和 iCloud 数据路径沿用现有存储机制。

## Apple 官方依据

- [Accessibility](https://developer.apple.com/design/human-interface-guidelines/accessibility)：支持系统辅助功能、大字体和可理解的操作语义。
- [Typography](https://developer.apple.com/design/human-interface-guidelines/typography)：系统字体与阅读优先级，避免细小难读的文本。
- [Buttons](https://developer.apple.com/design/human-interface-guidelines/buttons)：通常至少 44 × 44 pt 热区，清晰标签和系统状态。
- [Color](https://developer.apple.com/design/human-interface-guidelines/color)：深浅色、高对比度及语义系统颜色。
- [Materials](https://developer.apple.com/design/human-interface-guidelines/materials)：Liquid Glass 用于导航与控件层，内容层保持清晰。
- [Toolbars](https://developer.apple.com/design/human-interface-guidelines/toolbars)：突出高频动作，保留有意义的位置标题。
- [Lists and tables](https://developer.apple.com/design/human-interface-guidelines/lists-and-tables)：符合平台的列表样式、选择和组织层级。
- [Text fields](https://developer.apple.com/design/human-interface-guidelines/text-fields)：输入目的清楚，必要时保留独立标签。
- [Sheets](https://developer.apple.com/design/human-interface-guidelines/sheets)：聚焦当前任务，提供明确的关闭或完成动作。

页面正文通过 Apple 官方文档 JSON 读取。上表是针对本 App 的设计判断，不把每项改动都视为 HIG 的强制条款。

## 实施与验证

- 原始版及最终修改版均通过 Xcode 26.0 / iOS 26.0 Simulator 构建；最终构建记录为 `BUILD SUCCEEDED`。
- 实际检查了首页、设置、记录列表、零选择与全选工具栏、普通与批量标签、专注模式、工作流列表/详情、步骤说明、统计与 AI 会话空态。
- AI 示例点按后正确填入输入框；空输入时发送按钮禁用，填入内容后可用。
- 通过模拟器可访问结构检查：工作流按钮独立可达、标签已选/未选/部分选中状态、批量按钮禁用状态、步骤编辑与开关分离。
- iPhone SE（375 pt 宽）配合最大辅助功能字号、深色模式及提高对比度检查了首页、键盘、记录筛选和统计日期列表；工具条重叠、筛选区留白及月份断行已修复并再次截图确认。
- 5 项权限状态回归全部通过：允许及同会话复用、拒绝、等待中取消、展示前取消、超过 30 秒仍等待用户决定。测试直接编译生产权限管理器，并隔离配置存储。
- `git diff --check` 和回归脚本语法检查通过。

复现自动检查：在仓库根目录运行 `./apps/ios/tests/run-permission-checks.sh`。详细说明见 [测试说明](../apps/ios/tests/README.md)。

验证边界：本次未完成真机 VoiceOver / Switch Control 全流程实测，也未使用真实 AI 服务或 Mac 接收端进行端到端验证。设备授权弹窗采用代码审查和权限状态回归验证。构建中原有的 Bonjour 并发和 HistoryManager 的 await 警告仍存在。

模拟器使用独立演示数据。普通字号下的长工作流可横向滚动，最大辅助功能字号下从“选择工作流”菜单访问。
