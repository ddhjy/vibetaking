# 随心记全链路 UX Writing 审视与优化

日期：2026-09-05。范围：iOS 记录端、AI 助手和 Mac 接收端。下表中的问题均已落实到代码；“新增”表示原先没有对应说明或入口。

本次参考 Kinneret Yifrah 对语气、按钮、错误反馈、知识缺口和任务完成的关注，并按“说明状态、解释价值或用法、提供下一步”处理空状态。[《Microcopy: The Complete Guide》官方介绍](https://www.microcopybook.com/home1)，[作者的空状态指南](https://www.microcopy.co.il/post/empty-states)。

## 文案基准

面向打开 App 就想记下一句话的用户。语气保持轻巧、安静、直接；正常操作简短确认，失败时给出处理办法，删除、覆盖和授权时明确对象与范围。

- 输入中的内容称“草稿”，进入列表的内容称“记录”，AI 交互称“对话”。
- 统一使用“工作流”“步骤”“AI 助手”“AI 密钥”；API Key、模型 ID、HTTP 只在配置确有必要时保留。
- 操作按钮说明动作和对象；本机保存、发送请求、完成操作和 iCloud 同步分别表述。
- 延续“打开即写”，首次使用指引放在编辑页，不增加必须完成的介绍页。
- 项目没有推送通知功能。本次“通知”覆盖实际存在的页内反馈、加载状态和系统权限说明。

## 前后对比表

| 场景 | 优化前 | 已实现的文案或行为 | 原因 |
| --- | --- | --- | --- |
| 首次记录 | 只有“写下此刻的想法…” | 保留输入提示，新增“草稿随输入保存。要在记录列表中回顾，请运行含‘保存记录’步骤的工作流。”及“设置保存步骤”入口 | 解释草稿与记录的区别 |
| 首次 AI 使用 | 未配置时仍显示“向你的笔记提问”和示例 | “连接 AI，开始整理记录”；“连接 AI 服务”直接打开设置 | 发送前说明前提 |
| AI 空状态与输入 | “查找想法、整理记录…”；“问点什么…” | 说明示例可修改后发送、相关记录发往配置服务；输入提示“想查找或整理哪些记录？” | 减少起笔负担和数据去向疑虑 |
| 首次查看记录 | 直接要求运行保存工作流 | “草稿与已保存的记录分开存放。写好后，运行含‘保存记录’步骤的工作流，就能在这里回顾。” | 回答刚写的内容为何不在列表 |
| 本机空记录及同步 | “暂无本地记录”；承诺云端自动加载 | “本机还没有记录”；说明可继续记录，检查 Apple 账户及 iCloud 云盘后返回此页 | 不把环境可用写成同步完成 |
| iCloud 横幅 | “iCloud 暂时不可用，正在显示本地数据” | “iCloud 暂不可用，当前显示本机记录。请检查系统设置中的 iCloud 云盘。” | 明确当前范围和下一步 |
| 搜索与筛选 | “多个关键词用空格分隔”；显示整段搜索词；“清除筛选” | “空格分隔，匹配全部关键词”；无结果时建议缩短关键词并解释同时匹配；“清除标签筛选” | 说明搜索规则，避免长草稿挤满空态 |
| 首次添加标签 | “创建标签，方便之后找到相关记录。” | “给记录加上‘工作’或‘灵感’等标签，之后更容易找到。” | 用具体例子解释用途 |
| 单条／批量标签搜索 | 与首次使用共用说明，只能创建 | 区分尚无标签和搜索无结果；“试试其他名称，或把搜索内容创建为新标签。”；新增“清除标签搜索” | 搜索无结果也有退出路径 |
| 创建与重命名标签 | “添加”“保存”；合并说明较绕 | “创建标签”“保存名称”；说明自动选中和关闭时应用；重名时明确合并两组标签、正文不变 | 说明动作、时机和影响范围 |
| 批量标签 | “更改会应用于所选的 N 条记录” | 明确关闭时应用；解释减号及点按后会为全部所选记录添加标签 | 让符号与行为对应 |
| 助手技能为空 | 建立 _skills 后直接添加文件 | 明确 _skills/技能名/SKILL.md 结构；“刷新技能列表” | 与实际按子文件夹读取的代码一致 |
| 历史对话／统计为空 | “还没有会话”“本月还没有记录” | 对话增加“返回 AI 助手”；统计提示切换月份或查看全部日期 | 提供下一步 |
| 工作流术语 | 默认 Workflow、HTTP 发送、复制、AI 处理 | 默认工作流、发送到 Mac 或网址、复制文本、AI 改写文本 | 统一词汇，具体描述动作 |
| 空工作流 | “添加步骤来定义草稿的处理方式。” | “添加‘保存记录’即可保留想法，也可加入 AI 改写、复制或发送步骤。” | 用首个可完成的任务解释功能 |
| 工作流结果 | 未说明清空输入与是否保留结果 | 有步骤时说明运行会清空输入框；有保存步骤则全部完成后保存，无保存步骤则结果不进入记录列表 | 避免把草稿自动保存理解为自动归档 |
| 步骤排序与停用 | “编辑”、1/3、“已关闭” | “调整顺序／完成排序”；“已启用 1 个步骤，共 3 个”；“已停用，运行时会跳过” | 区分排序、配置和运行状态 |
| AI 步骤与保存说明 | AI 提示词／助手指令，空白编辑框；笼统保存说明 | 改写要求／任务指令，增加具体示例；说明最终文本在全部步骤完成后保存；“放弃修改／保存步骤” | 帮助填写，说明保存时机 |
| Mac 发送步骤 | 未说明空草稿的特殊行为 | “草稿为空时运行，会发送回车指令” | 避免意外触发接收端回车 |
| 设备状态与地址 | 在线／离线，自动重连；HTTP 配置；解除绑定 | 已发现，发送时连接／暂未发现，发送时会再次查找；手动填写接收地址；改为手动地址 | 发现结果不能证明在线或保证重连 |
| 设备发现失败 | 原始系统错误加权限路径 | 检查网络、Mac App、本地网络权限，再重新打开页面 | 保留可执行信息 |
| 记录页 CTA | 更多、导入、导出、统计、批量标签 | 记录操作、导入记录、导出全部记录、记录统计、编辑所选记录的标签 | 离开上下文也能理解 |
| 删除记录／工作流／步骤 | 取消、删除；部分后果未说明 | 保留记录／删除 N 条记录；保留工作流／保留步骤；显示数量、不可撤销及适用的 iCloud 删除同步范围 | 明确对象与后果 |
| 删除对话 | 只说对话不可恢复 | 明确删除消息；助手已保存的记录和已执行的设备操作不受影响 | 不暗示删除聊天可以撤销任务 |
| AI 配置字段 | API Key、API 地址、模型名称 | AI 密钥（API Key）、AI 服务地址、模型 ID，增加输入示例 | 保留必要术语并解释用途 |
| AI 配置说明 | “密钥已加密存储在本机。” | 说明密钥来自服务商、存入本机钥匙串，相关文本发往该服务；普通记录无需 AI；设置随修改保存 | 解释必要性、数据去向和保存方式 |
| 模型列表 | “正在获取…”“刷新列表”“暂无可用模型” | 正在获取可用模型／刷新模型列表；无模型时提示手动输入 ID 或检查地址；说明刷新不会改掉当前模型 | 给出加载之外的可用路径 |
| AI 记忆 | “跨会话记忆”；无条件同步说明 | “记住对话中的偏好”；说明后续使用方式，限定为 iCloud 可用时同步文件 | 从功能名转向使用结果 |
| 配置导出与覆盖 | 泛称包含密钥和覆盖配置 | 明确 AI 设置、全部工作流和可直接读取的密钥；覆盖确认列出密钥、地址、模型、工作流及不可撤销；“保留当前配置／替换配置” | 让用户理解文件与覆盖范围 |
| 配置迁移结果与错误 | “导入完成”“好”；文件太大／格式错误 | “配置已导入”“返回设置”；明确 5 MB、随心记 JSON 导出文件、更新两端版本并重新导出等处理办法 | 按原因提供下一步 |
| 记录导入结果 | “跳过 N 条重复或空记录”“没有新内容” | 纳入“无法解析的记录”；区分没有新增和导入成功；列明 .md、.markdown、文件夹及 ZIP | 与实际导入统计分支一致 |
| ZIP 导入错误 | 压缩方式编号、读取失败、太大 | 分别提示重新下载、先解压再导入、缩小超过 50 MB 的解压条目 | 用解决办法替代内部诊断 |
| 网络／文件错误 | 部分情况直接返回系统错误 | 分别处理断网、超时、连接失败、证书问题、文件权限和空间不足 | 按原因给出恢复办法 |
| AI HTTP／流式错误 | HTTP 状态、服务原文、内部错误码 | 密钥错误指向重新填写；模型错误指向地址／ID；限流提示稍后及额度；内容过长提示分次；服务故障提示稍后或联系服务商 | 避免所有错误只说重试 |
| AI 回复中断 | 英文 Response ended incomplete | 中文说明长度上限或提前中断，提示缩小任务或在对话中继续 | 让中断可以理解和接续 |
| 工作流失败 | “处理未完成”“知道了” | 具体工作流名称；检查工作流、适用时检查 AI 设置、继续记录；确认原文回到输入框后才提示恢复 | 提示、入口与实际状态一致 |
| 工作流加载与完成 | 图标加载，缺少可见结果 | 显示名称、当前步骤和总数；完成显示具体名称，复制成功说明剪贴板结果 | 让等待和结果可见 |
| 清除／恢复与空草稿 | 主要靠图标和读屏反馈；空草稿非 HTTP 操作无反馈 | 可见清除／恢复消息与读屏共用；空草稿提示先输入；HTTP 只确认回车指令已发送 | 不把发送请求写成最终粘贴或消息发送成功 |
| AI 主动停止 | “已取消”显示成红色错误 | 中性状态“已停止处理。已完成的操作会保留，可以继续发送消息。” | 停止不等于失败，也不撤销既有操作 |
| AI 工具与推荐 | 内部工具名；等待和标签推荐失败静默 | 中文动作名和可停止的等待提示；推荐中可手动选择，无结果／失败分别说明可继续手动选择 | 避免内部术语，保持核心任务可用 |
| 设备授权 | 直接允许／每段会话询问／禁止 | 始终允许／每次对话首次询问／不允许；解释范围、拒绝跳过该操作、系统权限独立 | 对应实际授权行为 |
| 权限用途与系统弹窗 | 笼统描述、Workflow、桌面端 | 用“允许后…”说明发现 Mac、发送文本、查询日程与提醒事项；剪贴板明确读取文字／图片、写入文字或清空 | 授权前理解能力和目的 |
| Mac 设置 CTA | 关于、复制、修改、查看、开机启动 | 关于随心记、复制地址、更改端口、查看记录、登录时启动 | 动作与对象一致，触发时机准确 |
| Mac 端口校验 | 非法值导致弹窗关闭，无反馈 | 保留输入，提示“端口需要是 1–65535 之间的整数”；说明当前端口未更改，可修改后保存或取消 | 让错误真正可修正 |
| Mac 空状态与保留范围 | “暂无记录” | 指引在 iPhone 工作流中选择这台 Mac 发送文字；说明保留最近 100 条，可选中复制 | 说明使用方法与数据范围 |
| Mac 网络／辅助功能／登录启动 | 未检测到地址／未授权／底层启动项错误 | 提示连接 Wi-Fi 或有线网络；说明自动粘贴需要辅助功能权限；启动失败指向重开 App、检查空间和权限 | 将缺失条件与下一步关联 |

## 第二轮审视与微文案优化 (2026-09-05)

依据 Kinneret Yifrah 的《Microcopy: The Complete Guide》，对微文案的情绪、认知负荷、行动力与状态一致性做深度打磨：

| 模块 | 优化前 | 优化后 | 改进理由 |
| --- | --- | --- | --- |
| 首次使用提示 | 草稿随输入保存。要在记录列表中回顾，请运行含“保存记录”步骤的工作流。 | 草稿随输入自动保存。添加“保存记录”步骤后，就能在记录列表中回顾。 | 移除新用户尚不理解的“运行”“工作流”多重概念，明确“自动保存”并突出“添加”动作。 |
| 首次使用 CTA | 设置保存步骤 | 添加保存步骤 | “添加”动词更直观，避免“设置”既可指“配置”又可指“设定”的歧义，与工作流空状态一致。 |
| AI 空状态（已配置） | 查找想法、总结内容，或给记录加标签。选一个示例，修改后发送。相关记录会发送到你设置的 AI 服务。 | 查找想法、总结内容，或给记录加标签。选一个示例，修改后发送。 | 空状态核心目标是引导起笔与提供下一步，数据去向在设置页已完整说明，避免重复制造焦虑。 |
| AI 空状态（未配置） | 填写服务商提供的 AI 密钥后，就能查找和整理记录。你仍可随时返回主页继续记录。 | 填写 AI 密钥后，助手就能帮你查找和整理记录。随时可以返回主页继续记录。 | 精简冗余词汇，引入“助手”主语增强协作温度，消除轻微的疏离感。 |
| AI 处理进度 | 助手正在处理，可随时停止… | 助手正在处理，可随时停止 | 状态已完整自洽，去掉结尾省略号，使控制权在用户的反馈更确定、轻巧。 |
